# Test case template (Given / When / Then)

Use one section per case: **TC-01**, **TC-02**, and so on.

## TC-01: Short title

- **Type:** Positive | Negative | Boundary
- **Priority:** High | Medium | Low
- **Source:** AC reference (for example AC2)
- **Given:** starting state and data
- **When:** action the user takes
- **Then:** observable outcome
- **Not in story:** `none`, or `FLAG —` what you assumed

## Open questions

- List anything the story cannot answer.
